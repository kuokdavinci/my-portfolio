<objective>
**Enhance Chatbot UX with visible feedback states, streaming effect, and smooth animations.**

Currently, the chatbot's local fallback (`generateChatbotAnswer`) is synchronous and instant, causing a **short circuit**: the thinking indicator is added to the DOM then removed in the same microtask — the browser never paints it. The answer also appears all at once with no visual transition, feeling robotic.

This plan fixes the short circuit and adds three UX improvements:

1. **Minimum thinking time** — Ensure the thinking dots animation is visible for ≥500ms even when the response is instant
2. **Streaming text effect** — Bot answer appears character by character (like the existing `setupTypingEffect` elsewhere in the portfolio)
3. **Smooth message animations** — New messages fade in and slide up with CSS transitions

Purpose: Make chatbot interactions feel natural and responsive regardless of backend availability.
Output: Updated `src/main.js` (askQuestion, addChatMessage, streamTextToElement) + updated `src/style.css` (message entrance animations)
</objective>

    **Problem:** Bot answers appear all at once with `addChatMessage()`, which feels robotic and unnatural — especially when the response is instant from the local fallback.

    **Fix:** Create a `streamBotResponse` function that renders the answer character by character, and modify `askQuestion` to call it instead of the current `addChatMessage` for bot responses.

    1. Create new function **before** `addChatMessage`:
       ```javascript
       /**
        * Renders bot response with a streaming (typing) effect.
        * Characters appear one by one at a natural pace.
        * @param {HTMLElement} container - .rag-chat-messages element
        * @param {string} content - The full bot answer text
        * @param {string[]} sources - Optional source citations
        * @returns {Promise<void>} Resolves when streaming is complete
        */
       async function streamBotResponse(container, content, sources = []) {
         const message = document.createElement('div');
         message.className = 'rag-chat-message is-bot is-entering';
         
         const sourceMarkup = sources.length
           ? `<div class="rag-chat-sources">${sources.map(source => {
               if (typeof source === 'object' && source.link) {
                 return `<a href="${escapeHtml(source.link)}" class="rag-chat-source-link">${escapeHtml(source.title)}</a>`;
               }
               return `<span>${escapeHtml(source)}</span>`;
             }).join('')}</div>`
           : '';
         
         // Create bubble with empty paragraph for streaming text
         message.innerHTML = `
           <div class="rag-chat-bubble">
             <p><span class="streaming-text"></span><span class="streaming-cursor">|</span></p>
             ${sourceMarkup}
           </div>
         `;
         
         container.appendChild(message);
         
         // Get the text span and cursor
         const textSpan = message.querySelector('.streaming-text');
         const cursorSpan = message.querySelector('.streaming-cursor');
         
         // Character-by-character rendering
         const chars = content.split('');
         let charIndex = 0;
         const charDelay = 15; // ms per character — fast but visible
         
         return new Promise(resolve => {
           function streamNext() {
             if (charIndex < chars.length) {
               textSpan.textContent += chars[charIndex];
               charIndex++;
               // Smooth scroll as text streams
               container.scrollTo({
                 top: container.scrollHeight,
                 behavior: 'smooth'
               });
               setTimeout(streamNext, charDelay);
             } else {
               // Streaming complete — remove cursor
               if (cursorSpan) cursorSpan.remove();
               container.scrollTo({
                 top: container.scrollHeight,
                 behavior: 'smooth'
               });
               resolve();
             }
           }
           streamNext();
         });
       }
       ```

    2. Replace `addChatMessage(messages, 'bot', ...)` calls in `askQuestion` with `await streamBotResponse(messages, ...)`:
       - In the try block (API success path): replace `addChatMessage(messages, 'bot', data.answer, data.sources)` with `await streamBotResponse(messages, data.answer, data.sources)`
       - In the catch block (fallback path): replace `addChatMessage(messages, 'bot', localResponse.answer, localResponse.sources)` with `await streamBotResponse(messages, localResponse.answer, localResponse.sources)`

    3. **Keep `addChatMessage` for user messages** — only bot responses should stream:
       - `addChatMessage(messages, 'user', trimmedQuestion)` should remain (line 591)
       - The initial greeting message (line 644-648): keep using `addChatMessage` since it appears on open, not after a question

    4. Add CSS for the streaming cursor in `src/style.css` within `@layer components` (near the `.thinking-dots` block):
       ```css
       .streaming-cursor {
         display: inline-block;
         animation: cursor-blink 0.8s step-end infinite;
         font-weight: 100;
         color: var(--color-on-surface-variant);
         margin-left: 1px;
       }
       
       @keyframes cursor-blink {
         0%, 100% { opacity: 1; }
         50% { opacity: 0; }
       }
       ```

    **Character delay rationale:** 15ms/char means a 100-char answer streams in ~1.5s — fast enough to not feel sluggish, slow enough to be perceivable. The user sees text appearing, not a wall of text.

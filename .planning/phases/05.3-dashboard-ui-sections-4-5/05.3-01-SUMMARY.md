## Decisions Made

- Container resources charts gracefully show "N/A" when cAdvisor metrics are unavailable (no error thrown)
- SSE endpoint enforces 10 concurrent client limit and 50-event queue per client for DoS mitigation
- SSE stream data is sanitized: only method, path, status, duration exposed (no request/response bodies, query params, or session IDs)
- Error rate uses cumulative Prometheus counters (5xx / total) rather than rate() for simplicity
- Deployment timeline derives from container_start_time_seconds and container_restart_count cAdvisor metrics

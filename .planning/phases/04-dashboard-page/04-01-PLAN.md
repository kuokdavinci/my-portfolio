<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → Prometheus API | Untrusted browser fetches from localhost:9090 — only readable metrics, no write access |
| Client → Grafana iframe | iframe loads from localhost:3000 — same-origin policy applies, no credential leakage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | Grafana iframe | accept | Grafana kiosk mode (`?kiosk=tv`) hides navigation/controls; only public dashboard visible. No PII exposed — only aggregate metrics. |
| T-04-02 | Spoofing | Prometheus API fetch | accept | Read-only queries (`sum()`, `count()`), no authentication tokens sent. Localhost-only in dev; production would use reverse proxy. |
| T-04-03 | Tampering | Dashboard DOM elements | mitigate | Stats are display-only (textContent updates), no form inputs or user-controlled data that could be manipulated to affect backend. |
</threat_model>

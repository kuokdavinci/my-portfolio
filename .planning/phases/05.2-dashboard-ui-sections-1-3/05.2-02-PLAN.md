```promql
# Chart A: AI Intent Categories

# Right axis - LLM generation time:
sum(rate(chatbot_llm_duration_seconds_sum[5m])) / sum(rate(chatbot_llm_duration_seconds_count[5m]))

# Chart C: Token Consumption (stacked area)
sum(chatbot_input_tokens_total)
sum(chatbot_output_tokens_total)

# Chart D: Estimated AI Cost
sum(chatbot_cost_usd_total)
# Derived: avg cost/query = sum(chatbot_cost_usd_total) / sum(chatbot_queries_total)

# Chart E: Cache Hit Rate (gauge)
sum(cache_hits_total) / (sum(cache_hits_total) + sum(cache_misses_total)) * 100
```
